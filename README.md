# DineOps

An Android application for restaurant ordering, table and hall reservations, and administrative record management.

![DineOps interface](screenshots/overview.png)

## Features

- Customer registration and sign-in
- Restaurant directory and menu selection
- Shopping cart and order summaries
- Table and hall reservations
- Customer, restaurant, pricing, and reservation records
- Feedback and contact information

## Development

The Android project is located in `DineOps`. Use JDK 17 or 21 and Android SDK Platform 34. The project uses Java, Android Gradle Plugin 8.5.2, and Gradle 8.9. Android 5.0 or later is required.

```sh
cd DineOps
./gradlew assembleDebug assembleDebugAndroidTest lintDebug
```

To refresh the screenshots with a running emulator:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -e phase after \
  com.dineops.app.test/com.dineops.app.ScreenshotRunner
cd ..
adb pull /sdcard/Android/data/com.dineops.app/files/screenshots/after screenshots/
```

## Current scope

Data is stored locally in SQLite. Ordering and reservation workflows are available for KFC; other restaurants appear in the directory. Cart quantity updates and some confirmation actions remain unfinished. Feedback currently displays an acknowledgement. Production authentication, payments, and a remote backend require further implementation.
